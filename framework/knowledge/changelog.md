**By**: Claude Opus 4.8 (instructed by user)

Deleted `framework/knowledge/skills-index.md`; repointed all references; refactored `.workspace/scripts/add-skill.sh` + `validate.sh`.
- **CLAUDE.md trim** — moved the first-time-setup steps to `setup-guide.md` § Step 3 (cuts always-loaded bytes); rewrote normal-startup to describe auto-injection.
- **Stale-rule fix** — `framework/instructions/global.md` commit conventions corrected from "default branch `dev`" to "always work on `main`" (matched `CLAUDE.md`).
